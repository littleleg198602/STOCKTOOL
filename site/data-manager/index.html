Přihlášení StockTool

01

Stačí se přihlásit jednou. Data Manager, BUY a SHORT Scanner potom sdílejí zabezpečenou relaci až 30 dní od posledního použití. Samotný klíč se v prohlížeči neukládá.

Ověření webového API ještě neproběhlo.

Jak propojit MetaTrader 5?

1. Na FORPSI vytvoř neveřejný soubor /stocktool.eu/stocktool-private/config.php s API klíčem (viz návod na GitHubu).

2. Na počítači s běžícím MT5 spusť StockTool-MT5-MULTI-TF.bat. Jeden Python konektor postupně načítá všechny akcie a časové rámce.

3. Poprvé zadáš přístupový klíč; Windows ho uloží šifrovaně pouze pro tvůj účet. V MetaTraderu 5 nic neinstaluješ.

4. Konektor najde akcie u brokera a synchronizuje samostatná originální MT5 data H1, H4, D1 a W1. Bez otevření jednotlivých grafů.

5. Na webu vlož klíč pouze při prvním přihlášení. Data Manager i BUY Scanner si pak přihlášení pamatují pomocí zabezpečené relace. Pro nové svíčky musí běžet MT5 i hromadný konektor na tvém PC.

Jak propojit MetaTrader 5?

1. Na FORPSI vytvoř neveřejný soubor /stocktool.eu/stocktool-private/config.php s API klíčem (viz návod na GitHubu).

2. Na počítači s MT5 spusť StockTool-MT5-START.bat. Používá hromadný Python konektor pro stovky symbolů.

3. Poprvé zadáš přístupový klíč; Windows ho uloží šifrovaně pouze pro tvůj účet. V MetaTraderu 5 nic neinstaluješ.

4. Konektor najde akcie podle seznamu symbolů u brokera a automaticky načte dokončené svíčky, bez otevření jednotlivých grafů.

5. Na webu vlož stejný klíč a klikni na Připojit. Pro nové svíčky musí běžet MT5 i hromadný konektor na tvém PC.

Hromadný Python konektor čte dokončené svíčky přímo z MT5, bezpečně je posílá na server a web je načítá přes API. Nové svíčky přicházejí při běžícím terminálu a konektoru. Data se mohou lišit mezi brokery a tick volume není skutečný burzovní objem. Odesílání musí odpovídat podmínkám brokera.

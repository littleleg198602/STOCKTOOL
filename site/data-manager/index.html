Jak propojit MetaTrader 5?

1. Na FORPSI vytvoř neveřejný soubor /stocktool.eu/stocktool-private/config.php s API klíčem (viz návod na GitHubu).

2. Otevři StockToolBridge.mq5, vlož ho v MT5 do složky MQL5/Experts a zkompiluj v MetaEditoru.

3. MT5 → Nástroje → Možnosti → Expertní poradci: povol WebRequest pro https://stocktool.eu.

4. Připoj poradce ke grafu, vyber symbol a interval, zadej stejný klíč. Modul pouze čte ceny, neobchoduje.

5. Otevři tuto stránku, vlož klíč a klikni na Připojit. MT5 musí běžet, aby přicházely další svíčky.
